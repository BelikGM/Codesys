# 60 Лет Октября — автоматика фонтана (ОВЕН СПК107 / CODESYS 3.5)

Проект сделан на основе "ДДЮТ" (который, в свою очередь, на основе
"Саки Пруд"). Дозация и добор воды управляются другим оборудованием —
контроллер здесь отвечает только за сухой ход, насосы-шоу
(мониторинг), насосы фонтана, подсветку и мониторинг фильтрации.

## Структура

- `src/` — все файлы .st проекта (GVL, PRG, FB, F-функции)
- `docs/LOGIC.md` — полное описание логики по разделам (по коду)
- `docs/SCREENS.md` — описание экранов визуализации, что убрать/добавить
- `docs/CONTEXT.md` — весь контекст объекта, тайминги, история изменений,
  открытые вопросы

## Файлы src/

Изменённые относительно ДДЮТ (полная новая версия):
- `GVL.st` — 3 насоса вместо 2
- `PRG_IO.st` — новый комментарий карты (логика без изменений)
- `GVL_Fountain.st` — новая карта переменных, рудименты помечены `не используется`
- `PRG_Fountain.st` — вся новая логика фонтана
- `PRG_Errors.st` — новый состав аварий
- `PRG_Pumps.st` — добавлен EMD_PUMP_3

Без изменений от ДДЮТ:
- `PLC_PRG.st`, `FB_SunsetRelay.st`, `FB_FountainSchedule.st`,
  `FB_TimeZoneSelect.st`, `FB_Pump.st`, `F_FormatLogTimestamp.st`,
  `F_FormatLogDateOnly.st`, `F_FountainLogWrite.st`, `F_PumpLogWrite.st`,
  `F_SelectModeText.st`, `F_LightScheduleModeText.st`,
  `F_PumpScheduleModeText.st`, `F_FaultCodeToText.st`

## Исключено из проекта

`PRG_PR200.st`, `PRG_PolivSPK.st` — оборудования нет вообще, файлы
не входят в репозиторий.

## Важно перед первой сборкой

В дереве Modbus проекта нужно добавить устройство **EMD_PUMP_3**
(адрес предположительно 43) — без него `PRG_Pumps.st` не
скомпилируется.
