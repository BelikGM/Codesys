# "60 Лет Октября" — экраны визуализации (текущее представление)

Экраны наследуются от проекта ДДЮТ. Ниже — что должно остаться,
что убрать, что добавить на каждом. Это ОПИСАНИЕ ПЛАНА, не факт —
реальный список элементов виден только в самом проекте OwenVisu,
здесь фиксируется предполагаемая структура для синхронизации.

## Главный экран

Оставить:
- `GVL.sSystemStateText`, `GVL.iErrors`, `GVL.xAnyAlarm`
- `GVL_Fountain.sAlarmCauses` — крупным текстом, сухой ход всегда
  первой строкой (порядок уже заложен в коде)
- `GVL_Fountain.xVseSist` — главный тумблер
- Статус насосов `sPermissionStatus`, статус света `sLightStatus`
- Кнопка сброса аварий: `xAskResetAlarms:=TRUE` → диалог →
  подтверждение `xAlarmReset:=TRUE; xAskResetAlarms:=FALSE`
- Лампа сухого хода: `xDryRunAlarm`
- Статус заслонки: `sDamperPosition` ("Открыт"/"Закрыт")

Добавить:
- Лампа "Опасно: сухой ход + ручная фильтрация" →
  видимость `xShowDangerDialog`
- Диалог с текстом предупреждения, кнопка "ОК" →
  `GVL_Fountain.xConfirmDangerDialog := TRUE;`

Убрать (рудимент ДДЮТ):
- Лампы "Уровень1"/"Уровень2" (`xLevel1`/`xLevel2`) — уровней в
  дискретном виде больше нет, всё приходит одним сигналом DI4
- Старый `sDamperFullStatus` с режимом заслонки

## Экран "Свет/Насосы"

Без изменений от ДДЮТ — тот же 3-позиционный селектор:
```
Насосы: iPumpSelect := 0/1/2  (Ручной/Выкл/Авто)
Свет:   iLightSelect := 0/1/2 (Ручной/Выкл/Авто-закат)
```
Статусы: `sPermissionStatus`, `sLightStatus`.

## Экран "Астрономич. реле"

Без изменений от ДДЮТ. Широта/долгота/часовой пояс/коррекция заката,
диагностика (`xIsWeekend`, `xSunsetActive`, `xSunsetCoordError`,
время до смены состояния).

## Экран "График фонтана"

Без изменений от ДДЮТ. Режим расписания света (4 положения) и
насосов (3 положения, без "Астро"), ручные времена будни/выходные,
общее время выключения. Все флаги видимости (`xLightShowInputFields`
и т.д.) уже считаются в FB_FountainSchedule, экран просто привязывает
напрямую.

## Экран "Заслонка/Добор"

Убрать почти всё (рудимент старой системы добора ДДЮТ):
- Все ручные форс-кнопки (`xDamperForceOpen/Close`)
- Селектор `iDamperSelect`
- Систему попыток добора (`iRefillAttempts`, `tRefillDurHours`,
  `tBetweenRefillHours`, `iRefillAttemptsMax`, `xRefillAttemptsAlarm`)
- Гистерезисы уровня, задержку выключения добора
- Режим 2/3 датчика (`iLevelSensorCountPending`)

Оставить только:
- `sDamperPosition` — "Открыт"/"Закрыт"
- Лампа аварии реле заслонки: `xDamperRelayAlarm`

## Экран "НФ/Фильтрация"

Оставить (счётчик промывок — без изменений от ДДЮТ):
- `xNfWork` (лампа "работает"), `iNfContinuousRunHour/Min/Sec`
- `iFilterMinRunMin` (порог, с экрана)
- Счётчик промывок: `iNfFlushCount`, время последней промывки,
  диалог сброса (`xAskResetNfFlush` → `xConfirmResetNfFlush`)

Добавить:
- Лампы режима: `xNfAutoSwitch` (DI11), `xNfManualSwitch` (DI12),
  текст `sNfModeStatus`
- Лампа аварии: `xNfManualRelayAlarm`

Убрать:
- `xNfEnable`-тумблер (был тупиковым ещё в ДДЮТ)
- Кнопку ручного пуска НФ (физического выхода под неё нет)

## Экраны pH / Альгицид / Биопаг

**Скрыть из меню целиком** — дозация на другом контроллере. Кнопки
перехода на эти экраны убрать из главного меню.

## Экран "Насосы" (COM2, ПЧ1/ПЧ2/ПЧ3)

Расширить с 2 до 3 колонок/блоков отладки. Переключатель выбора
насоса на экране отладки (`GVL.iDebugPumpSelected`) должен допускать
значения 1..3.

## Экран аварий

Пересобрать список согласно `docs/LOGIC.md` (раздел "Общая авария"):
1. Сухой ход (`xDryRunAlarm`) — ПЕРВЫМ
2. Сухой ход реле (`xDryRunRelayAlarm`)
3. Клапан добора реле (`xDamperRelayAlarm`)
4. Насосы фонтана реле (`xPumpRelayAlarm`)
5. Подсветка реле (`xLightRelayAlarm`)
6. Фильтрация реле, ручной режим (`xNfManualRelayAlarm`)
7. Связь ПЧ1/ПЧ2/ПЧ3 (`xPumpCommError[1..3]`)
8. Связь МВ-Д / МУ (`xMV110_Error` / `xMU110_Error`)

Убрать всё, что было про дозацию, попытки добора, датчики уровня.

Опасная ситуация (сухой ход + ручная фильтрация) сюда НЕ входит —
у неё отдельная лампа/диалог на главном экране.

## Экраны, полностью убираемые

- Экран ПР200 — оборудования нет вообще
- Экран "Полив СПК" — не применим
