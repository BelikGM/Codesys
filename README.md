# Codesys — монорепозиторий проектов CODESYS

Общая папка для всех проектов CODESYS (ОВЕН СПК107 и др.). Каждый
проект — отдельная папка в корне репозитория, со своей структурой
`src/` (файлы .st) и `docs/` (описание логики, экранов, контекста).

## Проекты

- `60-let-oktyabrya/` — автоматика фонтана "60 Лет Октября"
  (на основе проекта ДДЮТ)

## Как добавлять новый проект

1. Создать папку `<имя-проекта>/` в корне
2. Внутри — `src/` (все .st файлы) и `docs/` (LOGIC.md, SCREENS.md,
   CONTEXT.md — по аналогии с 60-let-oktyabrya)
3. README.md внутри папки проекта с кратким описанием и списком файлов
