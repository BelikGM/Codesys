# ДДЮТ — полный контекст объекта

Этот файл — саммари всего, что известно об объекте, для быстрого
восстановления контекста в новой сессии чата. Технические правила
CODESYS и логика по разделам — в `LOGIC.md`, экраны — в `SCREENS.md`,
исходный код — в `../src/`.

Текст ниже приведён дословно из исходного контекстного файла проекта
(колоночное выравнивание значимо, поэтому сохранён как есть).

```
====================================================================
ПРОЕКТ ДДЮТ — АВТОМАТИКА ФОНТАНА. ПОЛНЫЙ КОНТЕКСТ ДЛЯ НОВОГО ЧАТА
====================================================================
Этот документ целиком описывает текущее (финальное на сегодня)
состояние проекта — не как менялось, а КАК ОНО РАБОТАЕТ СЕЙЧАС.
Прочитай целиком перед тем, как отвечать на любые вопросы по проекту
или писать новый код — здесь есть неочевидные технические грабли,
которые легко наступить повторно, если их не знать заранее.

--- ЧТО ЭТО ЗА ПРОЕКT ---
CODESYS 3.5, язык Structured Text (ST), контроллер ОВЕН СПК107.
Автоматика фонтана: дозация pH/альгицид/биопаг, насосы фонтана,
свет с расписанием (в т.ч. по закату), заслонка добора воды,
фильтрация (НФ), промывки НФ, аварийная сигнализация, счётчики
наработки, журналы изменений параметров.
Сделан на основе более старого проекта "Саки Пруд" — многое
перенесено оттуда почти без изменений (архитектура шин/входов,
долговая система дозации), многое серьёзно переработано или
добавлено с нуля (см. архитектуру ниже).
Разработка велась в одном длинном чате, итеративно, через
конкретные баг-репорты и запросы на изменение — большая часть
архитектурных решений в этом файле есть РЕЗУЛЬТАТ реального
обнаружения проблем на объекте, не абстрактное проектирование.

--- ШИНЫ И АДРЕСА (Modbus) ---
COM1 (9600, 8N1): МВ110-16Д адр.1 (дискретные входы), МУ110-16Р
  адр.2 (дискретные выходы)
COM2 (38400): EMD-PUMP адр.41 (ПЧ1), адр.42 (ПЧ2)

--- КАРТА DI (МВ110-16Д, адр.1) ---
DI1/2 = ПЧ1/2 работа
DI3 = разрешение ПЧ
DI4 = контактор УФ (монитор)
DI5 = контактор НФ
DI6 = обратная связь DO13 (НЕ отдельный физ.вход сухого хода!)
DI7 = Уровень1 (0=сухой ход)
DI8 = Уровень2 (0=старт добора; в режиме 2 датчика также 1=стоп)
DI9/10/11 = подтверждение реле pH/биопаг/альгицид
DI12 = Уровень3 (в режиме 3 датчика: 1=стоп добора)

--- КАРТА DO (МУ110-16Р, адр.2) ---
DO1 = Свет
DO2 = авария (мигает)
DO9 = Насосы фонтана
DO11 = Клапан добора (1=открыть)
DO13 = NOT xDryRunAlarm (1=норма/0=сухой ход)
DO14 = Альгицид
DO15 = Биопаг
DO16 = pH

--- ПОРЯДОК ВЫЗОВА В PLC_PRG ---
PRG_IO() → PRG_Fountain() → PRG_Pumps() → PRG_Errors()
```
