## ПОДКЛЮЧИТЬ В ПРОЕКТЕ — пункты 6–10

Скачивать не надо, идут с CODESYS. Но их нужно **добавить в Менеджер
библиотек проекта**, иначе компиляция ругается на неизвестные типы.

### 6. Standard
`TON` (100 экземпляров в проекте), `TOF` (2), `R_TRIG` (2),
`CONCAT`, `LEN`, `WCONCAT`, `WLEN`.
Обычно уже подключена.

### 7. SysTimeRtc
`SysTimeRtcGet`, `SysTimeRtcSet`, `SysTimeRtcConvertUtcToDate`,
тип `SYSTIMEDATE`.
Используется в `PRG_Fountain.st` и `PRG_TimeCorrect.st`.
⚠️ Системная — в обычном списке скрыта, см. Место 3 ниже.

### 8. CAA File
Пространство имён `FILE`: `Open`, `Read`, `Write`, `Close`, `Delete`,
`GetSize`, `Flush`, `DirOpen`, `DirList`, `DirClose`, режимы
`FILE.MODE.*`, коды `FILE.ERROR.*`, дескриптор `FILE.CAA.HANDLE`.
Вся запись журналов на SD: `PRG_AlarmLogSD.st`, `FB_SdSpaceGuard.st`,
`FB_SdCardSize.st`.
⚠️ Дескриптор объявлять как `FILE.CAA.HANDLE`, а не `CAA.HANDLE` —
иначе ошибка «ссылка на объект не указывает на экземпляр».

### 9. CAA Types Extern
Зависимость CAA File, тянется сама. Отдельно добавлять не нужно.

### 10. VisuElems
Библиотеки визуализации, добавляются автоматически при наличии
Менеджера визуализации. Вручную не трогать.

**Modbus COM / Master / Slave** — не библиотеки, а описания устройств.
Идут с CODESYS и таргет-пакетом, добавляются в дерево, а не через
Менеджер библиотек.

## КУДА ЧТО ПОДКЛЮЧАЕТСЯ

Разные вещи ставятся в разных местах, и часть — на уровень среды, а не
проекта. «Установил, но не подключил в проекте» — самая частая ошибка.

### Место 1 — пакеты `.package` → уровень среды

```
Инструменты → CODESYS Installer → Install File… → выбрать .package
```

В старых версиях среды пункт называется `Менеджер пакетов → Установить…`
Требует перезапуска CODESYS. Ставится один раз на машину.

Сюда идут пункты **2** и **3**.

Проверка: `Файл → Новый проект → Стандартный проект` — в списке
устройств должен быть СПК1хх [М01]. Пустой проект не сохранять.

### Место 2 — внешние библиотеки `.library` → ДВА шага

Здесь застревают чаще всего: после первого шага библиотека уже
установлена, но проекту недоступна.

**2а — в хранилище среды (один раз на машину):**
```
Инструменты → Репозиторий библиотек… → Установить… → выбрать файл
```

**2б — в конкретный проект:**
```
Менеджер библиотек (двойной клик) → Добавить библиотеку… → имя → OK
```

Сюда идёт пункт **5**.

### Место 3 — встроенные библиотеки → только шаг 2б

Скачивать и устанавливать нечего, нужно только добавить в проект:
```
Менеджер библиотек → Добавить библиотеку… → имя → OK
```

⚠️ **Системные библиотеки (`SysTimeRtc` и прочие `Sys*`) в обычном
списке не показываются.** Нажать **«Дополнительно…»** (Advanced) и
включить отображение всех библиотек — только тогда найдутся поиском.

Сюда идут пункты **6**–**9**.

### Место 4 — драйверы и утилиты → обычная установка Windows

Пункт **4** и всё из раздела «по необходимости». К CODESYS отношения
не имеют. Драйвер USB требует перезагрузки ПК.

## ПОРЯДОК УСТАНОВКИ С НУЛЯ

1. Пункт **1** — распаковать, `setup*.exe` **от администратора**.
2. Перезагрузить ПК (ставится служба CODESYS Gateway).
3. Пункт **2** — таргет, Место 1. Перезапустить среду.
4. Пункт **3** — Mx110Drivers, Место 1. Перезапустить среду.
5. Пункт **4** — драйвер USB. Перезагрузить ПК.
6. Пункт **5** — Место 2, шаг 2а.
7. Открыть проект. При вопросе об обновлении версий устройств и
   библиотек — **ничего не обновлять**.
8. Открыть `Менеджер библиотек`, сверить с пунктами **6**–**10**.
   Чего нет — добавить (Место 2 шаг 2б / Место 3).
9. **F11** → должно быть **0 ошибок**.
